1. Abstract

The rapid evolution of modern software engineering requires collegiate students to discover internship opportunities that precisely align with their academic coursework and technical capabilities. Conventional job search portals aggregate thousands of unranked listings without transparent qualification analysis, leading to high rejection rates, candidate fatigue, and inefficient recruitment cycles. Furthermore, typical college projects frequently rely on legacy XAMPP/Apache/MySQL environments that suffer from port collisions, complex manual setup, and deployment fragility.

To address these challenges, this project presents the AI Internship Aggregator and Recommendation Platform, a complete full-stack web application developed using Node.js, Express.js, and an embedded SQLite database engine. The platform eliminates the need for XAMPP, providing zero-configuration, self-contained persistence. The system incorporates an automated natural language processing (NLP) resume extraction pipeline that parses both PDF and DOCX formats into structured skill vectors without requiring paid third-party API keys.

A transparent matching engine computes a deterministic Match Percentage:

Match Percentage (%) = (Number of Matching Skills / Total Number of Required Skills) × 100

The platform retrieves all eligible listings (exceeding 40+ curated opportunities across 25+ tech companies) without arbitrary caps or suppression of lower-match opportunities. An integrated Applicant Tracking System (ATS) manages applications across 8 status stages (Interested, Application Started, Applied, Assessment, Interview Scheduled, Offer Received, Rejected, Withdrawn) with personal notes and local interactive corporate portals, eliminating external browser SSL/privacy warnings.

3. Project Workflow & System Pipeline

The system executes an end-to-end 5-phase operational workflow:

Phase 1: Student Registration & Authentication
The student creates an account on register.html. Passwords are securely hashed with bcrypt and stored in SQLite. Upon login, a signed JWT token is issued and stored in client localStorage, authorizing subsequent protected API requests.
Phase 2: Resume Upload & Skill Extraction
The student uploads a PDF or DOCX resume on upload-resume.html. Multer validates file constraints and streams the document to the server. The parsing engine extracts raw text and matches it against a dictionary of 100+ technical competencies, updating the student's profile skills.
Phase 3: Recommendation & Gap Analysis
The recommendation service calculates intersection sets between student skills and internship requirements. Opportunities are sorted by match score descending. For each card, the student sees Matching Skills (green), Missing Skills (amber), and Suggested Skills to Learn.
Phase 4: Company Exploration & One-Click Application
Students can view full company headquarters details, view office locations on Google Maps, send email inquiries, or click Apply Now. Submitting records the application in SQLite, marks the status as Applied, and displays a celebratory confirmation modal. Dedicated local portals (demo-application-portal.html & demo-company.html) guarantee zero SSL/privacy errors.
Phase 5: Applicant Tracking System (ATS) Management
On applications.html, students monitor submissions across 8 lifecycle stages (Interested, Application Started, Applied, Assessment, Interview Scheduled, Offer Received, Rejected, Withdrawn). Students update stages, record interview notes, and review dynamic pipeline analytics. Multi-tenant isolation protects candidate privacy.

4. Relational Database Schema

  • users: Manages student credentials (id, name, email [UNIQUE], college_name, password [hash], created_at).
  • student_profiles: Stores academic details and extracted skills (id, user_id [FK], degree, grad_year, skills [JSON], phone).
  • resumes: Stores uploaded resume metadata and extracted text (id, user_id [FK], filename, extracted_text, detected_skills).
  • companies: Curated technology organizations (id, name [UNIQUE], description, logo_url, address, city, state, country, website, contact_email).
  • internships: Open opportunities (id, company_id [FK], title, category, work_mode, stipend, duration, required_skills [JSON], perks).
  • saved_internships: Student bookmarks (id, user_id [FK], internship_id [FK], saved_at, UNIQUE constraint).
  • applications: ATS tracking records (id, user_id [FK], internship_id [FK], company_id [FK], status, notes, click_timestamp, applied_at).

5. Conclusion

The AI Internship Aggregator and Recommendation Platform represents an efficient, modern solution for collegiate career discovery. By utilizing Node.js, Express.js, and SQLite, the application operates completely independent of heavy legacy stacks like XAMPP or MySQL. The transparent matching algorithm, automated resume parsing, interactive corporate portals, and integrated ATS dashboard equip students with an intuitive, professional career tool.
